# Project templates

Starting points that generate a Veneer profile, apply it, open a page and check the result.

| Template | Stack | Run |
| --- | --- | --- |
| [playwright-ts](playwright-ts) | TypeScript + Playwright | `npm install && npm start` |
| [puppeteer-js](puppeteer-js) | JavaScript + Puppeteer | `npm install && node main.js` |
| [python](python) | Python + Playwright | `pip install -r requirements.txt && python main.py` |

Each template prints the live report and compares the navigation request headers with the profile. Copy a folder out of the repository and adjust the constraints to start your own project.
